# Akinwale Akinfolarin — Portfolio

A one-page portfolio built for a Web Designer / UI Designer application.

## Before publishing
Replace these placeholders in `index.html`:
- YOUR_EMAIL@example.com
- YOUR_GITHUB
- YOUR_LINKEDIN

You can also add exported Figma/Adobe project images to the Visual Design section.

## Local preview
Open `index.html` in a browser, or run a simple local server:

python3 -m http.server 8000

Then visit http://localhost:8000
